# 브라우저 검증 체크리스트

코드와 단위 테스트로는 확인하지 못한 항목이다. `npm run dev` 후 `/editor.html`과 `/`에서 확인한다.
각 항목은 통과 / 실패 + 메모로 기록한다. 실패는 AC 번호와 함께 알려 주면 수정한다.

## 1. 치수 박스 (FR-09)
- [ ] 우측 패널 "치수 박스"에서 W/D/H를 입력해 추가하면 방 안 빈자리에 반투명으로 나온다 (AC-08-8)
- [ ] 비우거나 범위 밖(W·D 1~1000, H 1~500) 입력 시 필드별 오류가 보이고 추가되지 않는다
- [ ] 반투명 박스를 클릭·드래그할 수 있다. 반투명 벽 뒤에서도 그려지는 순서가 자연스럽다
- [ ] 색상 선택기를 끌어도 Undo 한 번에 한 색만 되돌아간다
- [x] 다른 가구와 겹치면 빨간 경고색이 나온다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 저장(JSON) 후 불러오면 이름·색·크기가 같다

## 2. 2D 치수 표시 (AC-12-4)
- [x] 2D 뷰에서만 가구 W×D와 벽 길이(cm)가 보인다. 쿼터·1인칭에서는 사라진다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 캔버스 하단 "치수 표시" 토글로 켜고 끈다
- [ ] 가구를 90° 돌리면 가로·세로 값이 교환된다
- [ ] L자 방과 좁은 홈에서 벽 라벨이 방 안쪽으로 파고들지 않는다
- [ ] 가구끼리 가까울 때 라벨이 읽을 만하다

## 3. 레이아웃·터치 (AC-16-3)
- [x] 데스크톱(1280px)에서 44px 버튼이 상단 바를 답답하게 만들지 않는다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 360px에서 상단 바가 두 줄이 되어도 메뉴와 토스트가 겹치지 않는다
- [ ] 모바일 시트(min/mid/full)가 동작하고 가로 스크롤이 없다
- [ ] 실기기 터치: 선택된 가구만 드래그되고, 선택 안 된 가구는 화면 스크롤이 우선한다 (AC-10-4)
- [ ] 방 대화상자 라디오·체크박스가 터치하기 편하다

## 4. 방 만들기·미리보기 (S-03)
- [ ] 방 대화상자 미리보기가 입력과 같은 모양이다 (직사각형, L자 방향)
- [ ] 방을 줄일 때 "N개 가구가 방 밖에 놓입니다"가 맞는 개수다
- [ ] 입력이 틀리면 만들기 버튼이 막히고 안내가 보인다

## 5. 경고 (FR-11)
- [x] 선택한 가구 패널에 경고 사유가 보인다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 문이 벽보다 넓을 때 "자리 없음" 경고가 나온다 (모서리 편집 후 포함)
- [ ] 같은 토스트가 연속으로 떠도 4초씩 보인다

## 6. WebGL 안내
- [ ] 브라우저 설정에서 하드웨어 가속을 끄고 `/editor.html`을 열면 안내가 뜨고 패널과 자동 저장은 동작한다
- [ ] 콘솔에서 `WEBGL_lose_context`로 컨텍스트를 잃으면 오버레이가 뜨고, 5초 뒤 새로고침 버튼이 나온다. 복구되면 화면이 돌아온다

## 7. 트레이싱 (S-04, FR-18~19)
- [ ] 실제 평면도 이미지로 기준선 → 모서리 클릭 → 방 생성이 된다
- [ ] 자동 모서리 제안(점선 후보)이 합리적이고 취소할 수 있다
- [ ] 모바일 폭에서 S-04가 쓸 만한가 (반응형 CSS 없음. 판단 필요)

## 8. 랜딩·광고·동의
- [x] 랜딩 히어로 소개 문구 위계가 자연스럽다 (impeccable 지적 해소 여부는 이 확인으로 대체) _(헤드리스 캡처 확인 2026-11-24)_
- [x] 광고 ID가 비어 있으면 광고 영역이 보이지 않는다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 가구 선택 시 제휴 카드(블록 아이콘·구간 문구)가 스크롤 없이 보이고, 바로 아래 고지 문구가 있다
- [ ] 속성 패널의 치수·위치·회전 입력(3열)이 좁은 폭에서도 깨지지 않는다
- [ ] 에디터 화면 어디에도 광고·제휴 링크 오표시가 없다 (제휴는 가구 선택 시 링크가 있을 때만)

## 9. 캡처·저장
- [ ] PNG 캡처 파일을 열면 3D 장면이 그려져 있다 (빈 이미지 아님)
- [ ] 새로고침 후 자동 저장본이 복원된다
- [ ] 예전 1.0 파일 불러오기 → 정상 표시, 저장하면 1.1 (실제 브라우저 확인은 사용자 몫)
- [ ] 깨진 JSON 불러오기 시 오류가 보이고 현재 작업이 보존된다 _(오류 모달 표시만 캡처 확인 2026-11-24, 작업 보존은 미확인)_

## 9-1. 공유·템플릿·가이드 (FR-14·15·21)
- [ ] 상단 바 "공유" → "캡처(치수·경고 포함)" PNG에 3D 장면과 아래 띠(방 치수, 경고 있음/없음)가 모두 있다
- [ ] 경고가 있는 배치에서 띠에 ⚠ 줄이 붉은색으로 나온다
- [ ] "공유" → "공유 링크 복사" 후 새 탭에 붙여 넣으면 덮어쓰기 확인이 뜨고, 확인하면 같은 배치가 열린다
- [ ] 주소가 깨진 `#d=` 링크는 오류 모달만 뜨고 현재 작업이 그대로다
- [ ] 랜딩 예시 배치 카드와 메뉴 "시작" → "템플릿 불러오기" 3종이 모두 경고 없이 열리고 Undo로 되돌려진다
- [ ] 모바일(390px)에서 상단 바 "공유"·메뉴 팝오버가 화면 안에 들어오고, 메뉴가 시작·파일·앱 그룹으로 보인다
- [ ] 랜딩 첫 화면에서 "예시 배치로 시작"과 헤더 "배치 가이드"가 눈에 띈다
- [ ] `/guide.html`이 모바일 폭에서 깨지지 않고, "이 배치로 시작"이 해당 템플릿 확인창을 띄운다

## 10. 다중 방 렌더·활성 방 선택 (스펙 §5.2·§5.4)
- [ ] 맞닿은 두 방(간격 0): 공유 면에 벽이 없다
- [ ] 10cm 간격 두 방: 하나의 벽으로 보인다(이중 블렌딩 없음)
- [ ] 30cm 간격 두 방: 가운데 빈 틈이 보인다
- [x] 활성 방 바닥이 구분되고, 비활성 방 치수 라벨이 옅다 _(헤드리스 캡처 확인 2026-11-24)_
- [ ] 다른 방 바닥 클릭으로 활성 방이 바뀐다
- [ ] 1인칭에서 다른 방 바닥 클릭 → 클릭 지점으로 이동하고 활성 방이 그 방으로 바뀐다. 카메라가 새 방 중심으로 튀지 않는다
- [ ] 비활성 방에는 모서리 핸들·벽 길이 편집이 나타나지 않는다
- [ ] 10cm 간격 이웃 벽에 문을 두면 문이 벽 띠 안에 놓인다(벽 밖으로 떠 보이지 않음)

- [ ] 빈 캔버스로 기존 방 왼쪽에 그려 문서가 이동해도 화면이 튀지 않고 다음 방이 맞게 붙는다
- [ ] 첫 점을 찍기 전(마우스만 움직일 때)에도 이웃 꼭짓점·변 근처에 스냅 마커가 보인다
- [ ] 스냅 마커가 보일 때 Shift를 누르면 해제된다, "이웃 방에 붙이기" 체크 해제도 동작한다 (알려진 한계: Shift 상태는 다음 포인터 이동까지 갱신되지 않는다)

- [ ] [끝내기] 뒤 메인 에디터 2D 줌이 모든 방을 담고 활성 방이 마지막으로 확정한 방이다
- [ ] 1방 사용자의 [그려서 만들기]→[방 생성] 흐름이 이전과 같다
- [ ] 방 추가 + 이미지 첫 방이 활성 방 오른쪽 10cm에 붙고 이후 윤곽·스냅이 나타난다
