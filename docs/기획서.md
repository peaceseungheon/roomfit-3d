# 프로젝트 기획서: 3D 가구 배치 시뮬레이터 (가칭: RoomFit 3D)

> **이 기획서와 `docs/PRD.md`가 다르면 PRD가 우선한다.** (타겟 확장, 가구 색상 블록 렌더링, AI 평면도 분석, 수익화 등이 PRD에서 바뀌었다.)

## 1. 프로젝트 개요

* **프로젝트명:** RoomFit 3D (가칭)
* **목적:** 이사 및 인테리어를 준비하는 사용자가 실제 가구 치수를 기반으로 가상 공간에서 배치를 시뮬레이션하고 동선 간섭을 사전에 검증할 수 있는 웹 기반 3D 유틸리티 서비스
* **타겟 사용자:** 원룸/투룸으로 이사하는 1~2인 가구, 가구 구매 전 공간 사이즈를 확인하려는 실용적 목적의 사용자
* **핵심 가치:** 화려한 3D 렌더링보다 실제 치수 검증, 낮은 입력 피로도, 높은 접근성(무설치/무가입)에 집중

## 2. 핵심 사용자 흐름 (User Flow)

사용자가 서비스에 접속하여 배치를 완료하기까지의 과정을 5단계로 정의합니다.

1. **즉시 진입 (Zero-Onboarding)**
* 별도 회원가입 없이 랜딩 페이지에서 '시작하기' 클릭 시 즉시 3D 에디터 진입
* 진입 시 조작법을 바로 체감할 수 있도록 '기본 원룸 샘플'이 렌더링된 상태로 시작


2. **공간(방) 생성**
* **프리셋 활용:** 직사각형, 'ㄱ'자형 등 기본 방 구조 선택 후 가로/세로/천장고(cm) 수치 입력
* **평면도 트레이싱:** 2D 평면도 이미지를 배경으로 업로드 후, 기준선 1개(예: 현관문 폭)로 축척을 설정하고 모서리를 클릭해 3D 벽체 생성


3. **고정 요소 및 간섭 영역 설정**
* 벽면을 클릭하여 현관문, 방문, 창문, 콘센트 마커 배치
* 문의 여닫이 방향 및 회전 반경을 바닥에 부채꼴로 표시하여 데드 스페이스 시각화


4. **가구 배치 및 치수 커스텀**
* 우측 패널에서 침대, 책상 등 기본 가구(약 15종) 선택 및 배치
* **치수 박스 모드:** 사용자가 실제 구매할 가구의 `가로(W) × 깊이(D) × 높이(H)`를 입력해 정확한 크기의 가이드 박스 생성
* 배치 보조(10cm 단위 그리드 스냅) 및 동선/문 열림 반경 침범 시 붉은색 경고 하이라이트 제공


5. **시점 검증 및 데이터 저장**
* 2D 평면 뷰(정밀 치수 확인) / 3D 쿼터 뷰(전체 공간감) / 1인칭 눈높이 뷰(실제 체감) 원클릭 전환
* LocalStorage 자동 저장 및 `.json` 파일 내보내기/불러오기를 통한 세션 유지 및 공유

## 4. 기술 아키텍처 및 스택 (Tech Stack)

### 4.1. 프론트엔드 프레임워크 및 상태 관리

* **코어 프레임워크:** React (Vite 기반), TypeScript
* **상태 관리:** Zustand (전역 상태 관리), Zundo (미들웨어를 통한 Undo/Redo 지원)
* **단위 기준:** Three.js 내부 좌표계 `1 unit = 1cm` 원칙 적용 (부동소수점 오차 방지)

### 4.2. 3D 렌더링 및 라이브러리

* **렌더링 엔진:** Three.js, React Three Fiber (R3F)
* **3D 유틸리티:** `@react-three/drei` (카메라 컨트롤, Outlines, HTML 오버레이 등)
* **상호작용 처리:** `@use-gesture/react` (부드러운 마우스/터치 드래그 이벤트)
* **에셋 관리:** `@react-three/gltfjsx` (GLB 에셋을 React 컴포넌트로 자동 변환)

### 4.3. 핵심 기술 구현 방안

* **방 구조 생성:** 모서리 2D 좌표 배열을 기반으로 Three.js `ExtrudeGeometry`를 사용해 벽체를 한 번에 돌출(Extrude)시켜 렌더링 최적화.
* **가구 드래그 앤 드롭:** `y=0` 좌표에 보이지 않는 Ground Plane을 배치하고, `Raycaster`로 마우스 교차점의 `x, z` 좌표만 추출하여 공중 부양 현상 방지.
* **충돌 및 간섭 감지:** 무거운 물리 엔진을 배제하고 Three.js의 `THREE.Box3` 간의 `intersectsBox` 메서드를 활용하여 문 반경 및 가구 간섭을 실시간으로 가볍게 연산.

## 6. 착수 후 진행 단계 (Next Steps)
