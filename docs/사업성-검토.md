# RoomFit 3D 사업성 검토

- 작성일: 2026-11-24
- 작성: `business-reviewer` 에이전트(sonnet)의 1차 검토 + 사용자가 확인한 쿠팡 파트너스 정책을 반영
- 기준 문서: `PRD.md`(기획서보다 우선). 이 문서는 **검토 의견**이며 PRD를 바꾸지 않는다. 변경은 §8의 결정을 거쳐 PRD에 반영한다.
- 신뢰 수준 표기: **[확인]** 공식 페이지·사용자 확인, **[제3자]** 검색 요약·블로그, **[추정]** 근거 없는 판단, **[확인 불가]**

## 1. 결론

**취미 프로젝트 수준이다. 틈새는 있으나 현재 구조로는 수익이 성립하기 어렵다.**

- 핵심 이유: 제휴 링크가 종류별 고정 검색 결과(AC-17-2)여서, 사용자가 입력한 치수(이 서비스의 핵심 가치)를 수익으로 연결하지 못한다.
- 현재 코드에서 `AFFILIATE_LINKS`와 `ADSENSE_*`가 비어 있어 수익 요소는 전부 숨김 상태다(PRD AC-17-5, AC-18-7대로 동작). 운영자 사전 작업(쿠팡 가입, 링크 변환, 애드센스 승인) 후에 켜진다.
- 검토 범위 한계: `wireframes.md`는 읽지 않았고 `src/`는 일부만 대조했다.

## 4. 쿠팡 파트너스 정책 (사용자 확인, 공식 약관 대조는 미완)

| 항목 | 내용 | 사업성에 미치는 영향 |
| --- | --- | --- |
| 수수료 | 일반 상품 기본 약 3%, 카테고리·프로모션별 차등. 가구 요율은 미확인 | 손익분기 계산 불가 상태 유지(PRD §11.4 원칙대로 수치 가정 금지) |
| 인정 범위 | 소개한 상품 외 다른 상품 구매도 인정. 자가 구매는 제외 | 링크 동작 테스트 구매는 수익으로 안 잡힘 |
| 쿠키 | 24시간. 24시간 내 장바구니에 담으면 89일. 라스트 클릭 귀속 | 약점 2 부분 완화 |
| 정산 | 월 마감 후 취소·반품 차감, 누적 1만 원 이상 시 익익월 15일경(약 45일 뒤) 지급 | PRD OPEN-03의 "15만원"은 지급 기준이 아니라 **API 최종 승인 기준**으로 읽어야 함 |
| 서브 ID | 채널 ID로 클릭·구매·수익 분리 조회. 생성 개수 한도 미확인 | 15종 링크의 종류별 성과 측정 가능성 |
| 링크 변환 | 검색 결과 페이지는 간편 링크로 변환. 딥링크 API는 최종 승인(누적 15만 원 판매) 후 API 키 발급 필요 | 아래 참고 |
| 게시 조건 | 활동 채널 URL을 사전에 계정에 등록, 대가성 문구 필수 | 배포 도메인 등록이 출시 전 운영자 작업에 추가됨 |

**딥링크 API의 의미:** Secret Key가 필요해 브라우저에서 치수별 링크를 즉석 생성할 수 없다. 키 노출 또는 서버가 필요해져 PRD §6(서버 없음)과 충돌한다. 따라서 치수 연동은 **구간별 링크를 사람이 미리 변환해 상수로 넣는 방식**만 현실적이며, 작업량은 종류 15 × 구간 수다.

**하지 않을 것:** AI 방꾸미기·사진 분석(핵심 가치와 거리, 서버·유료 API 필요), 브랜드 가구 DB(v2.0 제외 유지), 고급 렌더링, 방 스캔. 계정·Pro 플랜은 트래픽 데이터가 쌓인 뒤 재검토.

## 6. 차별화 방안

- **A. "구매 전 치수 체크"로 수익 접점 재설계** — 배치 결과를 "들어간다/안 들어간다"로 판정한 직후 구간별 링크 노출. 전제: 쿠팡 검색에 크기 조건을 넣어도 결과가 쓸 만해야 함(미확인). 위험: 수작업 선형 증가, 쿠팡 정책 변경.
- **B. 공유 가능한 방 판정 카드** — URL 해시 공유 + 치수·경고가 든 캡처로 커뮤니티 질문("이 배치 가능한가요?")에 첨부. 전제: 그런 수요가 있다는 근거는 아직 없음. 위험: URL 길이, 개인정보처리방침 반영.
- **C. 치수·동선 검증으로 좁힌 SEO 틈새** — 렌더링 품질 경쟁은 하지 않고 평형·가구별 정적 가이드로 유입. 위험: 대형 서비스도 "실제 비율" 문구를 쓰므로 문 부채꼴·충돌 경고 같은 구체 기능으로만 차별 가능.

## 8. 미결정 사항 (사용자 결정 필요)

1. **방안 A 검증 방식** — 권장: 침대 1~2종으로 폭 조건 검색어를 쿠팡에서 직접 시험하고, 쓸 만할 때만 AC-17-2를 변경. 대안: A를 접고 종류별 고정 링크 유지, 공유 URL·가이드 페이지 우선.
2. **PRD 갱신 범위** — 권장: OPEN-03의 정산 문구만 먼저 정정(15만원 = 승인 기준, 지급은 1만원 이상·약 45일 뒤). 나머지는 결정 1 이후.
3. **분석 도구** — PRD §6은 자체 분석 도구를 만들지 않는다고 했으나 §7 가설 중 일부는 외부 대시보드로 측정 불가. 외부 도구 허용 여부와 개인정보 고지(AC-01-4) 연동 결정 필요.

**결정 기록(2026-11-24):** 결정 1 = 방안 A 진행(운영자가 쿠팡에서 종류+치수 검색이 근사 결과를 내는 것을 육안 확인, 표 없음). 구간은 종류당 3개, 채널 ID 한도 10개라 구간(소·중·대) 3개로 사용. 구간 기준은 폭(W), 경계 치수는 PRD AC-17-8 표로 확정. 결정 2 중 OPEN-03 정산 정정과 AC-17-2/5/6/7은 PRD에 반영함. 결정 3(분석 도구)과 나머지 변경 후보는 미결.

**후속 결정(2026-11-24):** 방식 B 채택. 치수 박스에서 이름·치수를 직접 입력하고 종류(선택)를 고르면 제휴 링크가 붙는다(PRD AC-09-6). 싱글·퀸 침대는 `BED`로, 2인 소파는 `SOFA`로 합쳐 카탈로그는 14종, 링크는 14종×3구간=42개가 되었다.

PRD 변경 후보 전체: AC-17-2/5(구간 링크), FR-18·AC-18-1(광고 위치), §2·§6(공유 URL), §6(외부 분석 도구), AC-15-1(캡처 주석), OPEN-03(정산 문구), OPEN-04(애드센스 선행 조사), 신규 기능은 수익 가설 검증 후라는 우선순위 규칙.
