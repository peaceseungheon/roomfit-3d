# RoomFit 3D — 와이어프레임 (MVP v1.0)

> 기능 ID(FR-xx)·수용 기준(AC)은 `docs/PRD.md`를 따른다. 화면 ID는 PRD §5와 같다.
> 구간: **모바일 <640px / 태블릿 640–1023px / 데스크톱 ≥1024px** (PRD §9 기본값).
> 레이아웃은 구조 표현용 ASCII이며 시각 디자인(색·폰트)은 범위 밖이다. `[ ]` 버튼, `( )` 라디오, `▢` 입력, `⚠` 경고.

## 0. 공통 규칙

- 터치 대상 ≥44×44px, 가로 스크롤 없음 (AC-16-3).
- 경고는 붉은색 + `⚠` 아이콘 + 텍스트를 함께 쓴다 (색에만 의존하지 않음).
- 길이 단위는 항상 cm 표기. 치수 입력 순서는 **W × D × H**.
- 화면 간 이동은 URL 해시로 구분하지 않고 에디터 안의 시트/모달로 연다(랜딩 ↔ 에디터만 별도 문서로 로드).
- 광고는 랜딩(S-01) 콘텐츠 영역 안에만 둔다. 에디터 문서에는 광고를 두지 않는다 (PRD AC-18-1, 18-2).

```
│                                                            │
│              [   시작하기   ]                              │
│                                                            │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐                 │
│   │ 치수 입력 │  │ 문 열림  │  │ 시점 전환 │                 │
│   │ 박스     │  │ 경고     │  │ 2D/3D/1인칭│                 │
│   └──────────┘  └──────────┘  └──────────┘                 │
│ ── 사용법 ─────────────────────────────────────────────── │

│ ── 가구 치수 가이드 ───────────────────────────────────── │
│  (기본 가구 15종 치수표, 재야 할 치수 안내)                 │
```

위와 동일하되 소개 카드 3개를 2열로(2+1) 배치.

**상호작용**: "시작하기" → S-02 (AC-01-1). LocalStorage에 저장본이 있으면 저장본으로, 없으면 샘플로 열린다 (AC-01-2).

| 상태 | 표현 |
| --- | --- |
| 기본 | 위 레이아웃 |

| 오류(WebGL 미지원) | 시작하기 비활성 + "이 브라우저는 3D를 지원하지 않습니다. 최신 Chrome/Edge/Safari/Firefox를 사용하세요" |
| 경고 | 해당 없음 |

## S-02 에디터 (FR-01, 02, 05, 06, 07, 08, 10~13, 15, 16)

구성: 상단 바(시점 전환·Undo/Redo·저장 상태·메뉴) + 캔버스(3D/2D) + 우측 패널(S-05) + 경고 배지.

### 데스크톱 (≥1024)
```
┌────────────────────────────────────────────────────────────────────┐
│ RoomFit │ (2D)(3D 쿼터)(1인칭) │ [↶][↷] [스냅 ✓] │ 저장됨 ✓ │ [메뉴] │  ← 상단 바
├─────────────────────────────────────────────┬──────────────────────┤
│                                             │ ┌──────────────────┐ │
│                캔버스                        │ │  S-05 패널        │ │
│          (방 · 가구 · 문 부채꼴)              │ │  (섹션 스택,      │ │
│                                             │ │   세로 스크롤)    │ │
│  ⚠ 경고 2 ▸                                 │ │                  │ │
│  [치수 표시]                                 │ └──────────────────┘ │
└─────────────────────────────────────────────┴──────────────────────┘
```
우측 패널 고정 폭 약 320px, 캔버스가 나머지 폭을 사용.

### 태블릿 (640–1023)
```
┌──────────────────────────────────────────────────────┐
│ RoomFit │(2D)(3D)(1인칭)│[↶][↷]│ 저장됨 ✓ │ [메뉴]    │
├────────────────────────────────────┬─────────────────┤
│                                    │ S-05 패널        │
│            캔버스                   │ (섹션 스택,      │
│                                    │  폭 약 260px,    │
│  ⚠ 경고 2 ▸                         │  접기 가능 ◂)    │
│  [스냅 ✓][치수 표시]                 │                 │
└────────────────────────────────────┴─────────────────┘
```
태블릿에서 스냅·치수 표시는 캔버스 하단 도구 줄로 옮긴다 (AC-10-2, AC-12-4). 캡처는 모든 구간에서 메뉴(S-06)에 있다 (AC-15-1). `[치수 표시]`는 `aria-pressed` 토글이며 2D 뷰에서만 나타난다.
패널은 `◂`로 접으면 캔버스가 전폭이 되고 우측 가장자리에 `▸` 핸들만 남는다.

### 모바일 (<640)
```
┌────────────────────────┐
│ ≡  (2D)(3D)(1인칭)  [↶][↷]│  ← 상단 바 (메뉴는 ≡로 통합)
├────────────────────────┤
│                        │
│        캔버스           │
│                        │
│ ⚠ 2 ▸                  │
│ [스냅✓][치수 표시]      │  ← 하단 도구 줄 (좁으면 가로 스크롤 없이 줄바꿈)
├────────────────────────┤
│ ▔▔▔ (핸들 버튼)         │  ← 하단 시트 (S-05), 3단계 높이
│ 섹션 스택 내용          │     최소/중간/전체
└────────────────────────┘
```
하단 시트는 핸들 버튼을 눌러 최소 → 중간 → 전체 순으로 높이를 바꾼다(드래그·자동 최소화는 구현되어 있지 않다).
모바일 저장 상태(`저장됨 ✓` 등)는 `≡` 메뉴 안(S-06)과, 저장 실패일 때만 상단 바에 `⚠` 아이콘으로 표시한다.

### 캔버스 상호작용 (FR-08, 10, 11, 12)
| 입력 | 동작 |
| --- | --- |
| 가구 탭/클릭 | 선택(외곽선 + 이동·회전 핸들) |
| 선택 가구 드래그 | 바닥 평면 위 이동, 10cm 스냅 (AC-10-1) |
| 빈 곳 드래그 | 카메라 이동(2D) / 궤도 회전(쿼터) / 시선 회전(1인칭) |
| 핀치 / 휠 | 확대·축소 |
| 방향키(가구 선택 시) | 스냅 단위(켬 10cm / 끔 1cm)로 이동 (AC-10-5) |
| 패널의 고정 요소 버튼 → 추가된 요소를 벽을 따라 드래그 | 가장 긴 벽의 빈 구간 중앙에 추가한 뒤 벽을 따라 이동 (AC-06-2). 벽을 클릭해 배치하지 않는다 |
| `R` / `+90°` 버튼 | 90° 회전 |
| `Delete` / 삭제 버튼 | 선택 삭제 |
| `Ctrl/Cmd+Z` / `+Shift+Z` | Undo / Redo (AC-13-2) |
| 1인칭에서 바닥 탭 | 해당 지점으로 시점 이동 (AC-12-2) |

### 경고 배지와 목록 (FR-11)
```
 ⚠ 경고 2 ▸   →  ┌ 경고 목록 ───────────────┐
                 │ ⚠ 책상 · 문 열림 반경 침범 │
                 │ ⚠ 침대 · 벽 간섭          │
                 └──────────────────────────┘
```
항목 선택 → 해당 가구가 선택된다 (AC-11-4). 경고가 0이면 배지는 "문제 없음 ✓"로 표시.

### 2D 뷰 오버레이 (FR-12, FR-05)
```
   ┌──── 400 ────┐        모서리 점 ● 드래그 → 10cm 스냅
   │              │ 300    벽 선분 선택 → [길이 ▢ 300 cm] 입력 (AC-05-2)
   │   ┌──┐       │   └───┴──┴───────┘
   (치수 라벨은 [치수 표시] 토글로 표시/숨김)
```

| 상태 | 표현 |
| --- | --- |
| 기본 | 샘플 방(400×300, 문 1, 가구 2+) 또는 저장본 (AC-02-1) |
| 빈 | 가구 0개: 캔버스 하단 중앙에 "패널에서 가구를 추가해 보세요" 안내 |
| 오류(WebGL 미지원) | 캔버스 영역을 "이 브라우저는 3D를 지원하지 않습니다. 최신 Chrome/Edge/Safari/Firefox를 사용하세요." 안내로 대체. 패널 편집·자동 저장은 그대로 동작 |
| 오류(컨텍스트 소실) | 캔버스 전체 오버레이 "화면을 다시 불러오는 중…". 복구되면 오버레이가 사라지고, 5초 안에 복구되지 않으면 [새로고침] 버튼 표시 |
| 경고 | 간섭 가구 붉은색 하이라이트 + 경고 배지 (AC-11-1~4) |
| 오류(모서리 편집) | 편집으로 교차 다각형이 되면 원위치 + 토스트 "모서리를 옮기면 선이 겹칩니다" (AC-05-3) |
| 경고(고정 요소) | 모서리 편집 후 문·창이 들어갈 자리가 없으면 해당 요소를 `⚠ 자리 없음`으로 표시하고 유지 (AC-05-4) |
| Undo 불가 | [↶]/[↷] 비활성 (AC-13-3) |
| 저장 상태 | `저장됨 ✓` / `저장 중…` / `⚠ 저장 실패` (AC-14-5) |

## S-03 방 만들기 — 프리셋 (FR-03)

열림: 패널 `방` 섹션의 "새 방 만들기". 데스크톱·태블릿은 모달, 모바일은 전체 화면 시트.

### 데스크톱·태블릿 (모달)
```
┌─ 방 만들기 ──────────────────────────────┐
│ ( ) 직사각형 ( ) ㄱ자 [그려서 만들기]    │
│                                          │
│   미리보기(2D 윤곽)                        │
│                                          │
│ 가로 ▢ 400 cm    세로 ▢ 300 cm            │
│ (ㄱ자) 우상단 잘림: 가로 ▢ 150 세로 ▢ 120   │
│ 홈/돌출 추가: 벽 ▢1 (•)홈 ( )돌출          │
│   위치 ▢ 100 너비 ▢ 200 깊이 ▢ 100  [추가]  │
│   [마지막 지우기] [초기화]  추가 2개        │
│ 천장고 ▢ 230 cm                           │
│ 기존 가구가 있을 때만 표시:                  │
│   (•)유지 ( )삭제   ※ 되돌리기 가능          │
│                                          │
│            [취소]   [만들기]               │
└──────────────────────────────────────────┘
```
### 홈/돌출 추가 (AC-03-5~7)
- 미리보기(2D 윤곽)의 각 벽 중앙에 벽 번호(1부터, 꼭짓점 순서)를 표시한다. 벽 번호·위치·너비·깊이는 숫자 입력, 종류는 라디오(홈=안쪽/돌출=바깥쪽).
- 입력 형식 오류는 해당 필드 아래에, 범위·교차·상한 오류는 `role="alert"` 문구로 목록 아래에 표시하고 추가하지 않는다.
- `추가`·`마지막 지우기`·`초기화`는 터치 타깃 44px. 프리셋 종류를 바꾸면 추가 항목이 초기화된다.
- 프리셋 값 변경으로 기존 항목이 맞지 않게 되면 알림 문구를 보이고 `만들기`를 비활성화한다.
- **[임의 가정]** 너비·깊이 최소 10cm, 위치 기본값 0. 확정치가 아니다.

### 모바일 (전체 화면 시트)
위 항목을 한 열로 쌓고 하단에 `[취소][만들기]`를 고정한다. 키보드가 열려도 하단 버튼이 가려지지 않도록 입력 포커스 시 스크롤.

| 상태 | 표현 |
| --- | --- |
| 기본 | 현재 방 값이 미리 채워짐 |
| 빈 | 필드 비어 있으면 [만들기] 비활성 |
| 오류 | 범위 밖/비정수: 가로·세로는 "100cm 이상 {방 상한}cm 이하 정수", 천장고는 "180~400 사이 정수", ㄱ자 잘림은 "50cm 이상, 전체 크기보다 작게"를 필드 아래에 표시하고 [만들기] 비활성 (AC-03-3). `{방 상한}`은 OPEN-02 상수를 참조하며 문구에 숫자를 직접 쓰지 않는다 |
| 경고 | 기존 가구가 새 방 밖이 되면 "N개 가구가 방 밖에 놓입니다(경고로 표시)" 안내문 |

[그려서 만들기] → S-04(빈 캔버스, 배경 이미지는 선택).

**방 추가 모드(add)**: 제목 `방 추가`, 확정 버튼 `[추가]`, 기존 가구 유지/삭제 선택은 없다. 같은 [그려서 만들기] 버튼이 기존 방·가구를 보존한 채 S-04를 연다(AC-04-13).

## S-04 평면도 트레이싱 (FR-04, FR-05, FR-19)

**빈 캔버스로 시작**한다(AC-04-7). 진행 표시는 빈 캔버스에서 ① 그리기 → ② 방 생성 두 단계, 배경 이미지를 올리면 ① 이미지 업로드 → ② 축척 설정 → ③ 모서리 찍기 세 단계로 바뀐다(AC-04-8). 아래 도면의 이미지·기준선·축척 부분은 이미지를 올렸을 때만 나타난다.

### 빈 캔버스(기본)
```
┌ 평면도로 방 만들기 ─ ①그리기 ─ ②방 생성 ───────────────────────┐
│ ┌───────────────────────────────────────────┐ ┌─────────────┐ │
│ │ ┼───┼───┼───┼   격자(단위 cm)                │ │ 안내          │ │
│ │ ┼─●━━━━━━●┈┈┈┈○ 미리보기 선 + 240cm        │ │ ▸ 배경 이미지  │ │
│ │ ┼───┼───┼───┼                              │ │   올리기(선택) │ │
│ │                                           │ │ ☑ 수평·수직 고정│ │
│ │                                           │ │ 다음 점까지 길이│ │
│ └───────────────────────────────────────────┘ │ ▢ 240 cm [점 추가]│ │
│                                                │ [마지막 점 되돌리기]│ │
│                                [취소]          │ [닫기]        │ │
│                                                └─────────────┘ │
└──────────────────────────────────────────────────────────────┘
```
- 길이 입력: 마우스를 둔 쪽 방향(직각 고정이면 가까운 축)으로 길이만큼 점 추가(AC-04-11). 미리보기 선과 길이는 커서 위치에서 갱신(AC-04-10).
- 닫은 뒤: 선 위 클릭 = 점 추가, 점 클릭 = 선택 후 [점 삭제](3점 이하면 비활성) (AC-05-5, 05-6). [다시 편집]으로 다시 열 수 있다.
- 이미지 모드의 안내 영역에는 [배경 없이 그리기]가 추가된다(확인창).

### 데스크톱·태블릿
```
┌ 평면도로 방 만들기 ─ ①업로드 ─ ②축척 ─ ③모서리 ───────────────┐
│ ┌───────────────────────────────────────────┐ ┌─────────────┐ │
│ │                                           │ │ 안내          │ │
│ │     평면도 이미지 (2D 직교 뷰)               │ │ ① 이미지 선택 │ │
│ │       ● ─────────● 기준선                  │ │ [윤곽 자동 제안]│ │
│ │                                           │ │ ② 두 점 클릭  │ │
│ │                                           │ │   실제 길이   │ │
│ │                                           │ │   ▢ 90 cm    │ │
│ │                                           │ │ ③ 모서리 클릭 │ │
│ └───────────────────────────────────────────┘ │   [적용]      │ │
│                                                │   [되돌리기]   │ │
│                                                │   [닫기]      │ │
│                                [취소] [방 생성] └─────────────┘ │
└──────────────────────────────────────────────────────────────┘
```
### 모바일
```
┌────────────────────────┐
│ ←  ①업로드 ②축척 ③모서리 │
├────────────────────────┤
│                        │
│   평면도 이미지          │
│    ● ──── ● 기준선      │
│                        │
├────────────────────────┤
│ ② 두 점을 찍고 길이 입력 │
│ [윤곽 자동 제안] [적용]  │
│ [되돌리기]   [닫기]      │
└────────────────────────┘
```
`[적용]`은 점선 제안 점이 있고 축척이 설정된 뒤에만 활성화된다. 계산 중에는 `[윤곽 자동 제안]` 자리에 `분석 중… [취소]`가 표시된다 (AC-19-5, 19-8).

이미지 이동·확대는 두 손가락 드래그·핀치(데스크톱은 빈 곳 드래그·휠), 점 찍기는 한 번 탭. 실제 길이 입력은 하단 시트로 연다.

**상호작용**
- (이미지 모드) ① 파일 선택(PNG/JPG). 선택 즉시 캔버스에 표시. 빈 캔버스에서는 [배경 이미지 올리기(선택)]를 열어 같은 방식으로 올린다.
- ① 직후 안내 영역에 `[윤곽 자동 제안]` 버튼이 보인다(FR-19, 선택 사항). 누르면 브라우저 안에서 계산하며 이미지는 외부로 전송되지 않는다. 계산 중에는 `분석 중… [취소]`가 나타난다. 결과 점은 **점선**으로 표시되고, ② 기준선 설정 후 `[적용]`을 눌러야 실선이 된다 (AC-19-5).
- ② 이미지 위 두 점을 찍고 실제 길이(cm) 입력 → 축척 확정 (AC-04-2). 축척 전에는 ③ 비활성 (AC-04-5).
- ③ 모서리를 차례로 탭, 첫 점 또는 [닫기]로 닫기. 점 3개 미만이면 [닫기] 비활성 (AC-04-3). 직각 보정·길이 입력·마지막 점 되돌리기는 빈 캔버스와 같다(AC-04-9~12).
- 점은 드래그로 위치 보정, 스냅이 켜져 있으면 10cm 단위 (AC-05-1). 닫은 뒤 선 위 클릭으로 점 추가, 점 선택 후 [점 삭제] (AC-05-5).
- [방 생성] → S-02로 돌아가며 천장고는 기본 230cm, 이후 "새 방 만들기" 대화상자에서 수정. 기존 가구가 있으면 유지/삭제 선택을 먼저 묻는다 (AC-03-4).
- **다중 방 (AC-04-13~16)**: 닫은 뒤 확정 영역에 천장고와 `[방 생성]`·`[방 생성 후 다음 방 따기]` 두 버튼이 있다. 후자는 방을 확정하고 같은 이미지·축척으로 새 다각형을 시작한다(방 20개면 두 버튼 모두 비활성+사유).
- 첫 방을 확정하면 머리줄에 `방 N개 확정`이 보이고, 하단 `[취소]`가 `[끝내기]`로 바뀐다(진행 중 점이 3개 이상이면 확인창). 이미지 업로드·기준선·`배경 없이 그리기` 버튼은 숨겨진다.
- 이미 있는 방은 캔버스에 **옅은 윤곽**으로 보이고(겹쳐 닫으려 하면 해당 방 윤곽이 붉게), 그리는 점이 이웃 방의 간격 10cm 선 15cm 안에 들면 **스냅 마커**가 보인다. 배경 이미지로 방을 추가하는 세션은 첫 방을 확정하기 전까지 윤곽·스냅·체크박스를 숨긴다(이미지와 기존 방의 상대 위치를 알 수 없음). 안내 영역에 `☑ 이웃 방에 붙이기`(윤곽이 보이는 다른 방이 있을 때만)와 "Shift를 누르고 있으면 이웃 방 스냅이 꺼집니다" 안내가 나온다.

| 상태 | 표현 |
| --- | --- |
| 기본 | ① 단계, 업로드 안내 |
| 빈 | 이미지 없음: 점선 박스 "이미지를 끌어다 놓거나 선택하세요" |
| 오류 | 형식 불가: 토스트 "PNG 또는 JPG만 올릴 수 있습니다". 기준선 길이 0/비숫자: 필드 오류 (AC-04-1) |
| 자동 제안 진행/오류 | 진행 중 `분석 중… [취소]`. 윤곽을 못 찾거나 점 3개 미만·범위 밖·선 교차이거나 5초를 넘으면 "윤곽을 읽지 못했습니다. 직접 찍어 보세요"를 표시하고 트레이싱 상태는 그대로 (AC-19-7, 19-8) |
| 자동 제안(미확정) | 점선 점 + 안내 "축척을 설정하고 [적용]을 눌러 확정하세요". 방 생성 버튼은 비활성 (AC-19-5) |
| 안내(축척 전, 이미지 모드) | ② 완료 전에는 모서리 찍기가 비활성이며 "먼저 기준선의 실제 길이를 입력하세요" 안내를 표시 (AC-04-5) |
| 경고 | 교차 다각형: 교차 선분 붉게 표시 + "선이 서로 겹칩니다. 점을 옮기거나 되돌리세요" [닫기] 비활성 (AC-04-4) |

## S-05 우측 패널 (FR-06, 07, 08, 09, 11, 17)

데스크톱: 우측 고정 패널. 태블릿: 접이식 우측 패널. 모바일: 하단 시트. 내용은 동일하며 **탭 없이 섹션을 위에서 아래로 쌓은 한 열**이다(세로 스크롤). 순서: 선택 항목 속성 → 가구 추가(카탈로그) → 치수 박스 → 고정 요소 → 벽 길이 → 방. (구현에 맞춰 수정(2026-11-19))

### 섹션 [가구 추가]·[치수 박스] — 카탈로그와 치수 박스
```
┌ 가구 ─────────────────────┐
│ ┌────┐┌────┐┌────┐         │
│ │침대 ││책상 ││의자 │ ...     │  ← 15종 (PRD FR-08 표)
│ └────┘└────┘└────┘         │
│ ───────────────────────── │
│ 치수 박스                   │
│ 구매 예정 가구 크기를 입력하면 │
│ 반투명 박스로 배치해 봅니다.   │
│ 가로 W ▢ (빈 값) cm          │
│ 깊이 D ▢ (빈 값) cm          │
│ 높이 H ▢ (빈 값) cm          │
│ 이름(선택, 최대 100자) ▢      │
│ 색상 ▢■ #90caf9  [치수 박스 추가]│
└───────────────────────────┘
```
### 섹션 [선택 항목 속성] — 선택 시 맨 위에 표시 (가구/치수 박스 공통)
```
┌ 선택: 싱글 침대 ─────────┐
│ 이름 ▢                     │
│ 가로 W ▢ 100  깊이 D ▢ 200  │
│ 높이 H ▢ 45                │
│ 회전 ▢ 90°  [+90°]          │
│ 색상 ▢■                    │
│ [복제]            [삭제]    │
│ ⚠ 문 열림 반경 침범          │
│ ───────────────────────── │
│ [이 종류 상품 보기 ↗]        │  ← 새 탭, 종류별 사전 생성 링크
│ 제휴 링크입니다. 구매 시      │
│ 수수료를 받을 수 있습니다     │
└───────────────────────────┘
```
제휴 링크(FR-17)는 기본 가구 15종을 선택했을 때만 속성 영역 맨 아래에 둔다. 치수 박스에는 표시하지 않는다 (AC-17-1). 제휴 설정이 비어 있으면 링크와 고지 문구를 함께 숨긴다 (AC-17-5). 어떤 편집 동작도 이 링크를 거치지 않는다 (AC-17-4).
### 섹션 [고정 요소] — 문·창·콘센트
```
┌ 고정 요소 ────────────────┐
│ [현관문][방문][창문][콘센트] │
│ 추가 후 벽을 따라 드래그해    │
│ 위치를 옮깁니다.             │
│ 선택 시:                    │
│ 폭 ▢ 90  높이 ▢ 210         │
│ (창문) 바닥 위 높이 ▢ 90    │
│ (문) 열림 (•)실내 ( )실외    │
│ (문) 여는 방향 (•)좌 ( )우   │
│ [삭제]                      │
└───────────────────────────┘
```
창문·콘센트는 열림·여는 방향 항목을 숨기고, 콘센트는 폭·높이 대신 바닥 위 높이만 입력한다 (AC-06-5).
### 섹션 [방]
`새 방 만들기`(→ S-03, 그려서 만들기·천장고 입력은 이 대화상자 안), `모서리 편집`(`aria-pressed` 토글, 2D 뷰로 전환) + 편집 안내. 벽을 선택하면 별도 `벽 길이` 섹션에서 길이를 입력하고 [가운데에 점 추가]로 벽 가운데에 점을 넣을 수 있다. 꼭짓점을 선택하면 `꼭짓점` 섹션에 [점 삭제](꼭짓점 3개 이하면 비활성)가 나온다(AC-05-5, 05-6). **[임의 가정: 2D 편집 모드에서 이미 선택된 벽을 다시 누르면 그 위치에 점이 추가된다. 첫 클릭은 선택·길이 입력이라 의도치 않은 추가를 막는다.]**

| 상태 | 표현 |
| --- | --- |
| 기본 | 카탈로그 목록 |
| 빈(선택 없음) | 속성 영역에 "가구를 선택하면 치수를 바꿀 수 있습니다" |
| 오류 | W/D/H가 양의 정수가 아니거나 범위 밖: 필드 아래 "1~{최대} 사이 정수" 표시(가로·깊이 최대 1000, 높이 최대 500, PRD AC-09-4), 값 미반영 |
| 경고 | 선택 항목이 간섭 중이면 속성 하단에 `⚠` 사유 문구 |

같은 벽 겹침은 `⚠ 문/창이 겹칩니다`(AC-06-4).

## S-06 저장/불러오기 (FR-14, FR-15, FR-18)

열림: 상단 `[메뉴]`(모바일은 `≡`).
```
┌ 메뉴 ───────────────────┐
│ 저장 상태: 저장됨 ✓       │
│ [JSON 내보내기]          │
│ [JSON 불러오기]          │
│ [화면 캡처(PNG)]         │
│ [샘플로 초기화]          │
│ 광고·쿠키 동의: [허용 ○]  │  ← 언제든 변경, 다음 랜딩 방문부터 적용 (AC-18-6), 광고 설정이 비면 숨김 (AC-18-7)
└─────────────────────────┘
```
- 데스크톱·태블릿: 드롭다운. 모바일: 전체 폭 시트.
- [JSON 불러오기]: 파일 선택 → 검증 → 확인 대화상자 "현재 작업을 덮어씁니다. 계속할까요? (되돌리기 가능)" → 적용 (AC-14-3, 14-4).
- [샘플로 초기화]도 같은 확인 대화상자를 거치며 Undo로 되돌릴 수 있다 (AC-14-6).
- [화면 캡처(PNG)]는 현재 뷰의 캔버스만 내려받는다 (AC-15-1).

| 상태 | 표현 |
| --- | --- |
| 기본 | 위 목록 |
| 빈 | 해당 없음 |
| 오류 | 불러오기 실패: 오류 모달 "파일을 읽을 수 없습니다: `room.points[2]` 값이 숫자가 아닙니다" + [닫기], 기존 작업 그대로 (AC-14-3). 저장 실패: 상태 줄 `⚠ 저장 실패` + "JSON 내보내기로 백업하세요" (AC-14-5) |
| 오류(버전) | 버전이 다른 파일: "지원하지 않는 버전(1.0만 지원)" 오류 모달, 기존 작업 유지 |
| 경고 | 해당 없음 |

## S-07 공통 컴포넌트 (전체)

### 토스트
```
┌──────────────────────────────┐
│ ⚠ 모서리를 옮기면 선이 겹칩니다. │  ← 화면 상단 중앙(상단 바 아래), 모든 구간 동일, 4초
└──────────────────────────────┘
```
### 광고·쿠키 동의 배너 (FR-18)
```
┌──────────────────────────────────────────────┐
│ 광고를 표시하기 위해 쿠키를 사용할 수 있습니다.   │
│ 방·가구 데이터는 전송되지 않습니다.              │
│ 개인정보처리방침                                │
│              [거부]        [허용]              │
└──────────────────────────────────────────────┘
```
- 최초 진입 시 랜딩(S-01) 하단에만 표시한다. 에디터에서는 다시 띄우지 않는다(변경은 S-06).
- 응답 전에는 광고 요청을 보내지 않고 광고 영역을 접는다 (AC-18-5).
- 광고 설정이 비어 있으면 배너 자체를 표시하지 않는다 (AC-18-7).

### 확인 대화상자
```
┌──────────────────────────────┐
│ 현재 작업을 덮어씁니다.         │
│ 계속할까요?                    │
│ 되돌리기(Undo)로 복구할 수 있음  │
│        [취소]   [계속]         │
└──────────────────────────────┘
```
### 접근성
- 모든 아이콘 버튼에 `aria-label` (예: "실행 취소", "시점: 2D 평면").
- 키보드: 상단 바 → 패널 → 캔버스 순으로 Tab, 선택 가구 이동은 방향키(AC-10-5).

### S-07 상태

| 상태 | 표현 |
| --- | --- |
| 기본 | 토스트는 4초 후 자동으로 사라지고, 확인 대화상자는 선택 전까지 유지 |
| 빈 | 해당 없음 |
| 오류 | 토스트는 원인 + 다음 행동 한 줄. 문구 앞에 `⚠`를 붙이고 화면 읽기 프로그램용 `role="alert"`(일반 안내 토스트는 `role="status"`) |
| 경고 | 토스트는 한 번에 1개만 표시하며 새 토스트가 이전 것을 대체한다(겹쳐 쌓지 않음). 오류와 같이 `⚠` + `role="alert"` |
- 시점 버튼은 선택 상태를 `aria-pressed`로 노출.
