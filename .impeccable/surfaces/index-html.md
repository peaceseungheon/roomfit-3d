# Surface brief: RoomFit 3D (landing + editor + trace + modals)

Scope: Persuade landing (index.html, privacy.html) and Operate editor (editor.html, trace screen, dialogs). One world across both. Visitor mode: landing Persuade, editor Operate. Replacement of the incumbent blue-gray default look; PRODUCT.md, PRD, copy, layout structure and 44px targets are preserved.

Audience/job: individuals checking "does this furniture fit this room" before a move or purchase, on laptop or phone. Proof: the interface itself drawing a real floor plan with real cm dimensions.

## Direction contract

THESIS: The product is a Korean apartment sales floor-plan brochure that you can edit: the dimension chain (tick-ended measurement line with cm numerals) is the one signature, and it refuses the generic blue SaaS editor and the blueprint-cyan costume.
OWN-WORLD: White drawing-paper ground, deep navy ink (#0F3057) for linework, type and the committed shell (top bar, section rules), pale plan-blue (#EAF0F6) canvas, mid line-blue (#9FB3C8) hairlines, amber (#F2A900) only for selection and the active state, signal red only for collisions. Controls are standard web controls with square-ish 4px corners, navy outline default, navy fill when pressed or primary. Numerals tabular. Workhorse Korean sans. Furniture blocks keep their PRD kind colours.
STORY: A first-time visitor sees a real plan being measured, understands "put furniture in a room at true size and see what collides", and presses 시작하기; in the editor the same dimension-chain grammar frames every measurement, so cm values are always the most legible thing on screen.
FIRST VIEWPORT: Landing: left column headline, sub, primary 시작하기 button; right column an authored SVG floor plan (walls, door swing arc, bed, wardrobe, desk blocks) wrapped in navy dimension chains with cm numerals, one furniture block flagged red against the door swing. Editor: navy top bar with wordmark, view segmented control, undo/redo, snap; plan-blue canvas with the room; right white panel whose section headings sit on a dimension rule; collision badge bottom-left.
FORM: Korean apartment sales floor plan with dimension chains, position 1 on my ordered list (IMPECCABLE'S PICK card; the user chose it over the assigned direction), seed:797383f7a260ff65.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
